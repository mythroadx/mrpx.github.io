项目与运行

mrpx 是基于原 VMRP 项目整理的 Mythroad MRP 模拟器。它在 x86-64 桌面宿主中通过 Unicorn 执行 ARM Guest 代码，并桥接文件、网络、图形、输入和计时器等 Mythroad DSM 接口。桌面版本支持 Windows 与 Linux，WebAssembly 版本可在现代浏览器中运行。

  • 桌面版：默认启动 dsm_gm.mrp 应用列表。把 MRP 放入可执行文件旁的 mythroad 文件夹后从列表选择，也可用 Open MRP、Ctrl+O 或拖放打开。
  • 网页版：必须经 HTTP(S) 或 localhost 打开，不能直接双击 HTML 文件。可直接使用本站的在线试玩，或在本地 make serve PORT=18766 后访问 /build/web/main.html。
  • 会话数据：浏览器文件系统只在内存中，刷新页面即重置；桌面应用数据保存在运行目录的 mythroad 下。

操作与输入

网页版提供 21 键虚拟手机键盘，映射与桌面虚拟键盘一致：方向键 ↑ ↓ ← →，◧、◨ 为左右软键，☎ 接听、☎× 挂机，数字与 *、# 保持原始键值。物理键盘同样可用，建议先点击一次画布再按键。

桌面 Windows 版本额外提供 Rotate 90°（每次顺时针旋转 90°，四次复位）、Photo（保存当前方向 PNG 截图）与 Record（录制无声 H.264 MP4 到 captures）。录像依赖 Windows Media Foundation 与 H.264 编码器，部分 Windows N 系统需安装媒体功能包；Linux 与 Web 版本不提供截图与录像按钮。

Console 是 MRP 编辑框接口，不是命令行：应用请求输入时在其中填写并提交，取消会保留原文本。声音需手动点击“启用 / 恢复”，浏览器要求用户激活后才能启动 AudioWorklet。

兼容与安全边界

不同 MRP 可能包含脚本字节码、ARM/Thumb 原生扩展，或两者兼有。宿主的内存范围与 ABI 检查用于避免 Guest 越界访问宿主缓冲区，但不构成完整沙箱；运行来源不明的 MRP 仍需谨慎。

项目不是 ESP32 移植版，也不承诺兼容所有 MRP。桌面与 Web 的回归覆盖固定启动器、MPC 测试夹具与 ARM/Thumb 样例，不代表所有设备、网络服务、音频功能或第三方应用均可用。WAV/MP3 播放、部分机型的专有插件不在当前范围内。

Windows x64 + PowerShell 7 是参考环境。下表区分最低要求与已测版本，混用版本组合不保证兼容。首次构建需要联网下载 Emscripten ports、WASM 后端源码与 MIDI 音色，之后测试与网页运行不依赖第三方网络。

参考命令：

make main                          # 桌面构建，产出 bin/main.exe
make wasm-unicorn                  # 固定 unicorn.wasm 后端
make wasm                          # WASM 编译 + prepare-web
make serve PORT=18766              # 本地 HTTP 服务
make test test-build test-mrp      # 单元、构建入口与真实 MRP 回归

make wasm 会把 wasm/web 的 HTML/CSS/JS 与 manifest 中的种子复制到 build/web；部署必须完整提供该目录，不能直接打开源码 HTML。WASM 后端来自固定提交的 unicorn.wasm 源码并应用仓库补丁，需配套 libunicorn.a、libarm-softmmu.a、libunicorn-common.a 三个库，禁止混用旧产物。

来源与致谢

mrpx 源自 VMRP 原仓库，原 README 记载原作者为曾明。mrpx 延续其 ARM Guest 执行与 Mythroad DSM 桥接方向，并整理了现代仓库结构、桌面/Web 构建、测试与发布流程。

项目名称、发行包与网页运行文件使用 mrpx；为兼容保留的内部标识包括 include/vmrp、VMRP 编译宏和部分运行时环境变量。维护者说明中注明，本项目基于原项目并借助 AI 进行大规模重构整理，原有实现不作为维护者的原创成果；原项目作者与贡献者的工作应归属其各自作者。

研究资料

仓库保留了 Mythroad Guest 运行时、MRC SDK、ARM/Thumb 实验与 MRP/EXT/FMT 样本，统一放在 docs/research/。这些文件用于研究，不是桌面或 Web 构建的自动输入。

当前宿主直接加载的预编译 Guest 模块与 MRP 种子列在 assets/runtime/manifest.json。历史 Guest 源码与这些二进制之间尚未建立完整、可重复的生成对应关系：修改历史源码不会自动改变实际运行的 Guest。固定回归包单独保存在 tests/fixtures/mrp/，其哈希与用途有记录；研究时应保留原始样本，并用独立的新样本验证格式或 ABI 假设。

发布与校验

GitHub Actions 仅由推送 tag 触发，tag 必须是完整的稳定版本 vX.Y.Z；v1.2、v1.2.3-rc.1、v1.2.3+build、V1.2.3 不发布。每次发布生成三个 ZIP 与一个 SHA256SUMS.txt：

文件内容与运行要求
mrpx-vX.Y.Z-windows-amd64.zipWindows x64 原生程序、SDL2/工具链 DLL、固定种子与许可证，运行 bin/main.exe
mrpx-vX.Y.Z-linux-amd64.zipUbuntu 24.04 x86_64 程序、启动脚本；需系统 GTK4 与 SDL2 运行库
mrpx-vX.Y.Z-wasm.zip完整静态站点 web/，以及内嵌该站点的 Windows/Linux Go 服务器

ZIP 内的 SOURCES.txt 保留原 VMRP 来源说明。Windows、Linux 与 WASM 发行包均不包含 MPC 或阅读器，MPC 只作为测试夹具保留。
